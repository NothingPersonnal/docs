# Writing the Sonder player guide

- Write for players. No developer words, no internal code names.
- Say "hero". Town professions are "Trades" (French: Métiers), never guilds.
- Sonder is a mobile app. Never mention a browser.
- Trading, the hero marketplace and the auction house appear only on the roadmap.
- A hero's backstory is their past. Never call it generated.
- Do not use dashes or hyphens as punctuation. Write plain sentences.
- Only state what the game design docs, the game or the landing page support. Leave anything unclear out.
